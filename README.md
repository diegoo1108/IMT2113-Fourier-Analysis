# IMT2113-Fourier-Analysis
El Ramo IMT2113 es un ramo opcional para la licenciatura de ingeniría matemáticas en la Pontificia Universidad Católica. Este tiene como objetivo introducir conceptos del análisis de Fourier y aplicaciones en ingeniería

Se cursó este ramo el segundo semestre del 2025 cuando me encontraba en mi tercer octavo de licencitura.

## Proyecto
Este curso se centró mayoritariamente en el análisis matemático rodeando la transformada de Fourier, sin embargo, la última evaluación fue un proyecto de aplicación. La aplicación en ingeniería que se escogió fue la de la transformada de Radón en limpieza de imágenes sismológicas. Este repositorio contiene el informe final, la presentación y el código asociado.
